### 2. Краткие теоретические сведения
Каждому процессу в Linux при запуске ядро автоматически выделяет три базовых потока данных, идентифицируемых номерами дескрипторов (file descriptors):
* **0 (stdin)** — Стандартный ввод (по умолчанию клавиатура).
* **1 (stdout)** — Стандартный вывод результатов (экран).
* **2 (stderr)** — Стандартный вывод сообщений об ошибках (экран).

Разделение потоков `1` и `2` позволяет изолировать логи работы от отладочной информации. 
* Оператор `>` выполняет полную перезапись файла потоком `stdout`.
* Оператор `>>` выполняет дозапись в конец файла без уничтожения структуры данных.
* Переменные десятся на локальные (доступные внутри сессии текущей оболочки) и глобальные (экспортируемые в окружение через команду `export` и наследуемые дочерними процессами).

### 4. Ответы на контрольные вопросы

**4.1. Чем отличается перенаправление `>` от `>>`? Приведите пример.**
* `>` — затирает всё старое содержимое файла и записывает данные с нуля.
* `>>` — сохраняет старые данные и дописывает новую информацию строго в конец файла.
* *Пример:* `echo "new" > file.txt` (очистит файл и запишет "new"), `echo "add" >> file.txt` (добавит "add" второй строкой).

**4.2. В чем разница между `команда1 ; команда2` и `команда1 && команда2`?**
* Разделитель `;` запускает команды последовательно в любом случае (даже если первая упала с критической ошибкой).
* Оператор `&&` запустит вторую команду **только тогда**, когда первая завершилась успешно (вернула код выхода `0`).

**4.3. Как объединить стандартные потоки stdout и stderr в один файл?**
Для современных версий Bash используется конструкция `&>`:
```bash
команда &> file.txt
```
В универсальном стандарте POSIX потоки связываются перенаправлением дескриптора ошибок на дескриптор вывода:
```bash
команда > file.txt 2>&1
```

**4.4. Что такое алиас? Как сделать его постоянным в bash, zsh, fish?**
Алиас — это псевдоним (короткое имя), заменяющее длинную системную команду.
* В `bash` / `zsh`: прописать `alias имя='команда'` в файлы `~/.bashrc` или `~/.zshrc`.
* В `fish`: прописать `alias имя "команда"` в файл `~/.config/fish/config.fish`.

**4.5. Зачем нужно export перед переменной? Как сделать переменную окружения постоянной?**
`export` переводит локальную переменную текущей командной строки в глобальную переменную окружения, чтобы её могли наследовать дочерние программы (скрипты, редакторы). Чтобы сделать её постоянной, декларацию с `export` добавляют в конфигурационные файлы профиля (например, `~/.bashrc`).

**4.6. Какая команда позволяет посмотреть все текущие переменные окружения?**
Команда `env` или команда `printenv`.

**4.7. Как передать вывод одной команды на ввод другой? Приведите пример.**
С помощью оператора конвейера — вертикальной черты (`|`).
* *Пример:* `ls -l | grep "txt"` (вывод списка файлов передается на вход фильтру grep).

**4.8. Назовите основные отличия fish от bash в синтаксисе алиасов и переменных (по наблюдениям).**
В `fish` полностью отсутствует знак равенства `=` при присвоении. 
* Алиас в fish: `alias имя 'команда'` (в bash: `alias имя='команда'`).
* Переменная в fish: `set -x ИМЯ значение` (в bash: `export ИМЯ=значение`).
* Логическое "И" в fish пишется словом `and` вместо символов `&&`.

**4.9. Как в одном процессе перенаправить stdin из файла и одновременно stdout в другой файл?**
Используя комбинированное перенаправление в одной строке:
```bash
команда < input.txt > output.txt
```
